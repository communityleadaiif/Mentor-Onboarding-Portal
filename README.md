# Mentor Onboarding Portal 🌟

A modern, streamlined onboarding platform designed to empower mentors and simplify the integration process. Built with React, TypeScript, and Vite, featuring a premium design with dynamic nature-inspired elements.

## ✨ Key Features
- **Interactive Onboarding**: Step-by-step guidance for new mentors.
- **Premium Aesthetics**: Dynamic backgrounds with floating leaf particles and organic vine decorations.
- **Secure Documentation**: Integrated signature and PDF generation for onboarding documents.
- **Performance Optimized**: Built with Vite and Tailwind CSS for lightning-fast load times.

## 🚀 Getting Started

### Prerequisites
- **Node.js** (LTS version recommended)
- **npm** (comes with Node.js)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/communityleadaiif/Mentor-Onboarding-Portal.git
   ```
2. Navigate to the project folder:
   ```bash
   cd Mentor-Onboarding-Portal
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```

## 🛠️ Tech Stack
- **Framework**: React 19
- **Build Tool**: Vite 8
- **Styling**: Tailwind CSS 4
- **Animations**: Framer Motion
- **Utilities**: Lucide React, html2canvas, jsPDF

## 🛡️ Security
This project is configured with best practices:
- Environment variables for sensitive data.
- Optimized `.gitignore` to prevent leaking secrets.
